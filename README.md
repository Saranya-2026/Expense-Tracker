\# Expense Tracker



A responsive React application to manage and track daily expenses.



\## Features



\* Add, edit, and delete expenses

\* Search expenses

\* View expense summaries

\* Visualize expenses using charts

\* Responsive user interface



\## Technologies Used



\* React

\* JavaScript

\* Vite

\* React Context API

\* useReducer

\* React Router

\* HTML and CSS



\## How to Run



Clone the repository:



```bash

git clone https://github.com/Saranya-2026/Expense-Tracker.git

```



Install dependencies:



```bash

npm install

```



Start the application:



```bash

npm run dev

```
